# Artifacts — Improving artifacts


Each year there is a chance for artifacts to gain additional effects if certain requirements are met. Historical artifacts cannot gain such effects. Some improvements have multiple levels, but it will only advance one level each time, even if the requirement for higher levels are met. If an artifact has an effect of one type, it can not gain other types in this table.

The "A Relic In Hand…"-event can give you the option to embed one artifact into your current weapon, gaining the modifiers of the embedded artifact.

### Courtier improves artifact

Each year there is a chance a courtier or knight will offer to improve one of your artifacts. Only weapon or armor that is not cursed and not improved by this event can gain this bonus. Accepting the offer will give the courtier a hook or gold, The bonus gain is base on the skill of the helper

| Skill | Effect |
| --- | --- |
| Reaver | **+10%** Raid Speed |
| Open Terrain Expert | **+4%** Heavy Cavalry Toughness |
| Forest Fighter Jungle Stalker Desert Warrior Winter Soldier Berserker | **+4%** Heavy Infantry Toughness |
| Rough Terrain Expert Blademaster | **+3%** Knight Effectiveness |
| >= 20 Skilled Tactician Brilliant Strategist Varangian | **+4** Prowess |
| already have same bonus | **+6%** Heavy Infantry Toughness |

### Grand Tournament Artisan improves artifact

|  | Available only with the Tours and Tournaments DLC enabled. |
| --- | --- |

Visiting the Artisan Quarters on the Grand Tournament Grounds may give you an option to improve one of your artifacts. You are often given an option between at least 2 different modifiers, such as:

- Piety/month or Prestige/month
- Prowess or Durability

Artifacts can get this improvement multiple times. Some of the modifiers you can get are temporary.
