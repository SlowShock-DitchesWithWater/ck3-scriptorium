# Situation — The Silk Road


The Silk Road situation showing the movement of innovations

|  | Available only with the All Under Heaven DLC enabled. |
| --- | --- |

The Silk Road situation affects all rulers with their capital in one of the situation regions. There are 6 situation regions, connected in the following order: Occident < Transcaspia and India < Central Asia and Tibet < China. Every region has an innovation assigned and every 12 years a random innovation discovered by the Han culture will be assigned to the China situation and all existing innovations will move westwards. These innovations can be researched normally by cultures with Chinese heritage or the Sinophilic tradition as well as if a ruler of that culture controls the region's hub while the innovation is present in the region. Other rulers can attempt to unlock these innovations by taking the Visit a Silk Road Market decision and passing the skill challenge.

How each ruler is affected depends on the phase in their region and their participant group.

The situation has the following catalysts:

- **+30** If a Grand Canals great project in completed in China
- **+20** If a Grand Canals great project in completed in Central Asia or Tibet
- **+10** If a Grand Canals great project in completed in India or Transcapia
- **+15** If a Bazaars special building is constructed
- **+15** Yearly if there are no wars in the region
- **+10** Yearly if there are no wars in any adjacent upstream region
- **+10** Yearly if there are no wars in any distant upstream region
- **+5** Yearly if the Dynastic Cycle situation is in the Stability phase
- **+15** If the Iranian Intermezzo ends
- **+5** If a Nomadic or Herder holding is feudalized
- **-5** Yearly if there is a war in any distant upstream region
- **-10** Yearly if there is a war in any adjacent upstream region
- **-15** Yearly if there is a war in the region
- **-10** If a county on the Silk Road route is raided
- **-15** If a county on the Silk Road route is besieged by the Greatest of Khans
- **-50** If the Byzantine Empire title is destroyed
- **-3** Yearly if Iranian Intermezzo phase is Unrest
- **-50** If an Expand the Steppes decision targets the situation region
- All regions will change phase to Hardship if the Dynastic Cycle situation enters the Division phase
