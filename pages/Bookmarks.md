# Bookmarks

> [!] Please help with verifying or updating older sections of this article.
> [!] At least some were last verified for version 1.19.
>
> [!] This article is for the PC version of Crusader Kings 3 only.

Upon starting a New Game from the main menu,  Crusader Kings III has eight bookmarks recommending prominent starting characters in both start dates. Many of these characters are required or otherwise well-suited for getting certain achievements.

Alternatively, players can choose to play any landed ruler; see interesting characters and Historical characters for more recommendations.
