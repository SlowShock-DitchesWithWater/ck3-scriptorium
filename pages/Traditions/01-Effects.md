# Traditions — Effects


A Cultural Tradition with many effects

**General effects**
  - These are the listed in bullet-point at the top of a tradition. Their descriptions sometimes do not describe all of their effects so hidden bonuses may be listed in the tables below. These effects also uniquely utilize Parameters, Each described effect is tied to a specific parameter and having multiple of the exact same parameter will only apply the effect once. Example: Prolific Hunters and Avid Falconers both provide an effect of **−50%** Hunt Cooldown time. They both achieve this by applying the parameter: `more_frequent_hunts`, If a culture has both traditions the total cooldown would still be **−50%**, because the game only checks whether a parameter is present, not the quantity of the parameter.

**Character effects**
  - These apply to any character of that culture. If it is a Command Modifier, it requires the commander of the battle to be of that culture to apply.
**Counties effects**
  - These apply to county level resources like Control and Development. If an effect is conditional (like on the presence of a certain terrain) it will only apply once per county per condition. Example: Forest Wardens provides **+15.0%** Development Growth in counties with forest and taiga. If a county with the tradition had 3 baronies of forest and 1 of taiga, the total effect would be **+30.0%**.

**Holdings effects**
  - These apply to holding (barony) level resources like Building Cost and Supply Limit.
