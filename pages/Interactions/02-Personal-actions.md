# Interactions — Personal actions


### Send Gift

Send a payment of  gold to the target for an opinion boost. This action will incur a medium stress penalty for  Greedy characters and a medium stress loss for  Generous characters.

### Sway

Begins a Sway scheme with the target to increase opinion.

### Befriend

Begins a Befriend scheme with the target to become friends. Requires either the Befriend lifestyle perk, or to have the final Adventure dynastic legacy and be targeting a vassal.

### Seduce

Begins a Seduce scheme with the target to become lovers.

### Romance

Begins a Romance scheme with the target to gain prestige.

### Elope

Begins an Elope scheme with the target to marry them.

### Educate Child

Choose a character to educate one of your children. This will increase the child's skills and allow them to gain traits from the guardian in the chosen education path

### Offer Ward

Sends request to selected character to educate a chosen child

### Offer Guardianship

Sends offer to parents/guardian of a child to allow a chosen educator

### Influence Ward's Personality

|  | Available only with the Wards and Wardens DLC enabled. |
| --- | --- |

Pass a Personality Trait on to the ward or a child hostage that is **at least 4 years old**, up to **4 personality traits**. This interaction has a cooldown of  3 years.

On success: Child adopts the selected personality trait,  **+20** opinion with each other, influencer gains  **20** stress and loses  **-75** prestige.

On failure:  **-20** opinion with each other, influencer gains  **40** stress and loses  **-75** prestige.

The acceptance chance of a trait is modified by the following (default value is 0):

| Source | Success Chance |
| --- | --- |
| Opinion of the influencer | Half the child's opinion of the influencer |
| Influencer's diplomacy skill | Half the influencer's diplomacy skill |
| Influencer's learning skill | Half the influencer's learning skill |
| Influencer's has a Wet Nurse employed | **+10** |
| Influencer has the Groomed to Rule perk | **+20** |
| Trait is a virtue for the child's faith | **+10** |
| Trait is a sin for the child's faith | **-10** |
| Child's Childhood Trait is compatible with the trait | **+15** |
| Child's Childhood Trait is not compatible with the trait | **-15** |
| Number of traits the influencer shares with the child | **+5** per matching trait |
| Number of opposite traits the influencer has with the child | **-5** per opposite trait |
| Child is intimidated by influencer | **+25** (Affected by Guile Legacy 5) |
| Child is terrified of influencer | **+50** (Affected by Guile Legacy 5) |
| Child already has 3 personality traits | **-50** |

### Host as Honored Guest

Characters following a faith with the  Ritual Hospitality tenet may honor another character with a ritual celebration. This interaction cannot be used on characters considered Hostile or Evil by the sender's faith, are ill, commanding an army, at war with sender, or is a courtier in sender's court. This interaction spends piety scaling with the rank of character, and grants **+20**  opinion boost with the target (increased by another **+10** if they are  Zealous and same faith, decreased by **-10** if they are  Cynical or follow faith with Ritual Hospitality, and increased by **+10** if  Arrogant.

This interaction gives  Shy and  Cynical characters **+20** .

### Make Shieldmaiden

With the Northern Lords installed, a Norse character following any Norse faith can appoint a close female relative as a  Shieldmaiden, provided the faith's View on Gender doctrine isn't set to Equal. If the faith's view on gender doctrine is set to Female Dominated, this interaction can instead be used to appoint a male relative as a Shieldswain.

### Abandon Hook

Characters with the  Forgiving trait can expend a hook they have on another character, reducing  **-65** stress for  strong hooks and  **-30** stress for  weak hooks. The target will gain a decaying **50** opinion bonus with the forgiver. Note that house head hooks cannot be "forgiven".
