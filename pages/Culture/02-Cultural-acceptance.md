# Culture — Cultural acceptance


Cultural Acceptance determines how much  Opinion penalty two cultures have towards each other. For every culture the culture with the highest Cultural Acceptance will be selected for Culture Spread, which increases the speed at which progress is gained towards an innovation the culture doesn't know but the other culture does by **+40%**. If the Royal Court DLC is enabled, it also determines whether two cultures of different heritage can create a hybrid culture. The baseline acceptance between two cultures will be the following:

- **+20** if both cultures have the same heritage
- **+10** if both cultures have the same language
- **+10** if both cultures have the same ethos and are located within adjacent counties or the same geographic region
- **+10** if more than half of the counties with both cultures follow the same faith
- **+5** if more than half of the counties with both cultures follow the same religion
- **+5** if more than half of the counties with both cultures follow a dharmic religion
- **+10** if more than half of the counties with both cultures follow a rite with the Pluralist doctrine and are located within adjacent counties or the same geographic region
